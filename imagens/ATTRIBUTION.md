# Imagens de referência

Fotos em `imagens/` são **referências visuais** do tipo de prato (não são fotos das
receitas manuscritas da família). Aparecem só na tela (`no-print`); não saem na
impressão A5.

A maioria veio do [Wikimedia Commons](https://commons.wikimedia.org/) via API de
busca (licenças abertas diversas). Ao substituir uma imagem, preferir fontes com
licença livre e manter o crédito aqui se necessário.
